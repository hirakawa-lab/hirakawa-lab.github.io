3. 手順

3.1. FMOD Studioのインストール

  • https://www.fmod.com/download

  • version 2.03

  • 実行ファイルは C:\Program Files\FMOD SoundSystem\FMOD Studio 2.xx.xx\FMOD Studio.exe

3.2. テンプレートファイルの準備

  • https://modding.scssoft.com/wiki/Documentation/Engine/Sound/Modding

  • Downloads のリンクから、テンプレートファイルをダウンロード

  • 任意の場所に展開する

    template
│  template.fspro
│
├─assets
├─build
├─metadata
└─plugins

  • template.fspro の名前はあらかじめプロジェクト名に合わせて変更しておく。

3.3. 音声ファイルの準備

  • フォーマット

    • wav, 2ch, 48000kHz (サンプルレートの制限は不明)

    • 公式では ogg ファイルとなっているが、wav でも問題ない（ビルド時にエンコードされていると推測）

  • compound_…​ と and_then_…​ は複合操作系で、先に compound_ が来た後、 and_then_ が続く

  • Multi-inst (ランダム) に推奨されているのは、start, finish, recomputing, u_turn

3.4. FMOD Studio でプロジェクト (*.fspro) を開く

  • テンプレートが古いのか、以下のメッセージが表示されるが、continue でプロジェクトファイルをマイグレートする

3.5. 音声ファイルの登録

  • Assets タブに *.wav ファイルをDrag & Drop

3.6. Bankの作成

  • Banks タブで右クリック > New Bank

    • 適当に名前を付ける (e.g. japanese_kiritan)

3.7. Eventの作成

  • Assets タブで *.wav ファイルを複数選択

    • この時、1つのイベントに複数の *.wavファイルを割り当てるもの（ランダム選択させるケース）は選択しない

      • ファイル名が {event}_1.wav としているもの

    • 右クリック > Create Events

      Create Eventのメニューが以前と比べて増えているが以下を選択

  • 1つのイベントに複数の *.wavファイルを割り当てる場合は、次のようにする

    • ファイルを選択して右クリック > Create Events

      長い再生時間のwavファイルに [stream] の表示が付くことがあるが気にしなくてよい

3.8. EventをBankに割り当て

  • Events タブから、生成されたイベントを複数選択して、右クリック > Assign to Bank > 作成したBank

  • Multi Instのイベントは、イベント名が New Event,New Event 2,…​ のような名前になっていてわかりにくいの rename しておくとよい

3.9. Mixer Routingの設定

  • メニュー Window > Mixer Routing を選択

    イベントを全部選択して navigation に Drag & Drop

3.10. ビルド

  • メニュー File > Build

  • メニュー File > Export GUIDs

    • プロジェクトルート > build フォルダ内に生成される

      ├─build
│  │  guids.txt
│  │
│  └─-
│          japanese_kiritan.bank
│          master.bank
│          master.strings.bank

      非常に見にくいが、フォルダ - 配下に *.bank ファイルが生成される

      guids.txt はビルド前に存在しているが、これは完全なファイルではないので使わない。 メニュー File > Export GUIDs で出力されたものを使う。

3.11. MODファイルの作成

  • MODファイルの構成は以下のようになっている (拡張子 .scs だが実態は無圧縮zip)

    └─Navigation_JPN_kiritan
    │  kiritan.jpg
    │  manifest.sii
    │  mod_description.txt
    │
    └─sound
        └─navigation
                japanese_kiritan.bank (1)
                japanese_kiritan.bank.guids (2)
                japanese_kiritan.sii
    1 build/-/ 配下からコピー
    2 build/GUIDs.txt を名前を変更してコピー
    GUIDs.txt のリネームは拡張子を間違えやすいので注意。よくある間違いとして .bank のつけ忘れがある。MODは認識されているのに音が鳴らない場合は、ファイル名間違いを疑う。

  • その他のファイルは自前で用意する

    *.jpg

    MOD表示画面でのサムネイル画像. サイズは \$276 xx 162\$ pixel

    manifest.sii
    SiiNunit
{
# ".package_name" does not matter as the dot at the beginning of the file means that this unit is anonymous.
# Please keep this form to not make any conflicts with other mod packages (name collisions).
mod_package : .package_name {

    # Package version can be any string with any length.
    package_version: "1.0" (1)

    # Display name can be any string with any length.
    display_name: "日本語音声ナビ- 東北きりたん" (2)

    # Author can be any string with any length.
    author: "Hirakawa.blue" (3)

    # Categories is an array of strings.
    category[]: "sound" (4)

    # Icon inside the root directory of the mod.
    icon: "kiritan.jpg" (5)

    # Description file inside the root directory of the mod.
    description_file: "mod_description.txt"
}
}
    1 バージョン
    2 MOD表示名
    3 作者名
    4 音声ナビを示すカテゴリー(固定)
    5 MODサムネイル画像
    mod_description.txt
    東北きりたん(VOICEROID)を使用した日本語音声ナビです。

効果音は以下の素材を使用しています。
- 効果音ラボ: https://soundeffect-lab.info/
- OtoLogic: https://otologic.jp/
    *.sii
    SiiNunit
{
voice_navigation_config : .japanese.kiritan.pack (1)
{
	pack_name: "日本語 - 東北きりたん(ver.1.2)" (2)
}
}
    1 MODのシステム内ユニークネーム
    2 表示名

  • 無圧縮zip形式でまとめる

    一番上のフォルダは含めないことに注意

    展開した時に次のようになること

    │  kiritan.jpg
│  manifest.sii
│  mod_description.txt
│
└─sound
    └─navigation
            japanese_kiritan.bank
            japanese_kiritan.bank.guids
            japanese_kiritan.sii

  • 拡張子を .zip から .scs に変える

3.12. MODファイルの配置

  • %Userprofile%\Documents\Euro Truck Simulator 2\mod 配下に *.scs を置く
